# Auditrail Web

Auditrail is a security audit-event explorer built with Next.js, React, and TypeScript. It provides an interface for searching, filtering, and inspecting audit events.

## Features

- Search and filter audit events
- Filter by severity, service, action, and time range
- Browse event details and load additional results
- Authentication using email magic links
- Session-aware API requests
- Copy event information with success and failure feedback
- Accessible UI states for loading, empty results, and errors

## Tech Stack

- Next.js
- React and TypeScript
- Tailwind CSS
- TanStack Query
- Zod
- Vitest and React Testing Library
- Playwright and axe for end-to-end and accessibility testing

## Requirements

- Node.js compatible with the installed Next.js version
- npm
- A running Auditrail API instance

## Getting Started

Install dependencies:

```bash
npm install
```
